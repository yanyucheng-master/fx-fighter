# FX Fighter

**Play online: [https://fxfighter.netlify.app/](https://fxfighter.netlify.app/)**

FX Fighter is a browser game about leveraged foreign exchange trading with virtual money. Call the direction of a currency pair, choose your exposure, and manage stop-loss and take-profit levels while random price movements and unexpected events put your account under pressure. The default Easy game starts with **JPY 300,000** and aims for **JPY 20,000,000** in account equity.

Prices, economic releases, and news are generated by a local simulation. All money and profits are virtual. The model illustrates trading concepts and game mechanics; it does not provide live market data, reproduce every broker's rules, or offer investment advice.

## How to play

1. Choose the Easy, Learn, or Pro interface and start a new game.
2. Switch between USD/JPY, EUR/JPY, and GBP/JPY and watch the price chart.
3. Buy when you expect the price to rise; sell when you expect it to fall. Easy and Learn interfaces size a trade through leverage, while Pro uses lots directly.
4. Optionally set a stop loss and take profit before entering a trade, or close positions manually. Easy uses yen amounts for these inputs; Learn and Pro use pips.
5. Watch equity, margin level, and the economic calendar. Larger exposure magnifies losses when the market moves against you. A gap can cross a stop price and produce a worse execution price.
6. Keep trading after reaching your goal. If you cannot afford the minimum trade, restart or take an in-game bailout to continue.

## Interface modes

| Mode | Intended audience | Presentation |
| --- | --- | --- |
| Easy | First-time players who want to start immediately | Plain-language explanations and an HP-style risk gauge; fixed starting capital, goal, and account type |
| Learn | Players who want to learn trading concepts as they play | Trading terminology with explanations and coach prompts; configurable capital, goal, and account type |
| Pro | Players familiar with FX terminology | Direct lot sizing and fewer teaching prompts; configurable capital, goal, and account type |

These modes change the interface and teaching aids. New games currently share the same market difficulty. You can switch interfaces during a game.

## Simulation rules

- **Account currency: Japanese yen.** The `¥` symbol represents yen. One lot is 10,000 units of the base currency, and the minimum trade is 0.1 lots. For these JPY pairs, one pip is JPY 0.01, worth JPY 100 per lot.
- **Bid, ask, and spread:** Buys enter at the ask and sells at the bid. Spreads change with events and market sessions.
- **Account tracking:** The game shows balance, unrealized P/L, equity, used and free margin, total deposits, and net P/L after deposits.
- **Stops and targets:** Triggered orders settle at the currently available execution price. Gaps can cause slippage.
- **Stop-outs:** When margin level reaches the account's stop-out threshold, the game closes every open position and explains the liquidation.
- **Weekend closure:** The clock uses Japan Standard Time. Closed weekends skip to the next opening and can introduce a price gap.
- **Bailouts:** An exhausted account can be topped up to JPY 100,000. The top-up counts toward total deposits rather than trading profit.

Learn and Pro offer the following account choices for new games. The domestic account uses the game's Japan-regulated account setting:

| Account setting | Maximum account leverage | Margin-level stop-out threshold |
| --- | --- | --- |
| Domestic / Japan-regulated | 25:1 | 50% |
| Offshore | 400:1 | 20% |

## Features

- Three currency pairs: USD/JPY, EUR/JPY, and GBP/JPY.
- Canvas charts with 1-minute, 5-minute, 15-minute, and 1-hour candles and a 20-period moving average.
- Simulated NFP, CPI, central-bank decisions, interventions, flash crashes, black swans, breaking news, and weekend gaps.
- Economic calendar, news feed, open positions, trade history, win rate, maximum drawdown, and other statistics.
- Beginner coach, glossary, liquidation-price markers, and risk explanations. Easy mode uses recent volatility to visualize a vulnerable portion of the HP gauge.
- Pause and resume controls and 1x, 3x, 10x, and 30x simulation speeds.
- English and Chinese interfaces; light, dark, and system themes; selectable red/green price conventions.
- Browser-local saves and preferences, plus report images that can be saved with a right-click or long press.
- Responsive desktop and narrow-screen layouts.

## Keyboard shortcuts

| Key | Action |
| --- | --- |
| `B` | Buy |
| `S` | Sell |
| `X` | Close all positions |
| `Space` | Pause / resume |
| `1`, `2`, `3`, `4` | Select 1x, 3x, 10x, or 30x speed |

Trading shortcuts are inactive while an input is focused or a dialog is open.

## Run locally

Download this repository and open `index.html` in a modern browser. You can also serve the repository with any static web server. For example, if Python is installed:

```bash
python -m http.server 8080
```

Then open <http://localhost:8080/>. The game requires no backend, Node.js installation, dependency installation, or build step.

The page loads fonts from Google Fonts and falls back to system fonts if they are unavailable. The dedicated report-image download button requires a host-provided download interface; in a regular browser, right-click or long-press the generated image to save it.

## Saves

Game progress and preferences are stored in the current browser's `localStorage`. Different browsers, devices, domains, and local-file versus online sessions have separate saves and do not synchronize automatically. Clearing site data removes the local save.
